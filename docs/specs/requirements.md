# pmx-editor-mcp 要求仕様書

この文書は**この製品への要求**を定める。何をツールへ写すか・どう写すか・どう検査するかは
コードとテストと機械可読のデータが持ち、この文書は**何を満たすか**だけを持つ。

要求は2つに分かれる。**作業の要求**は、エンドユーザーがこの製品で何を成し遂げられるかを定める。
**作業に依らない要件**は、作業のどれにも先立って製品が満たすものを定める。

作業を成し遂げたいのはエンドユーザーで、ツールを呼ぶのはエンドユーザーが使うMCPクライアントの
エージェントである。**要求が数える呼び出しの回数は、MCPのツール呼び出しの回数である。**

## 作業の要求

### PMXエディタのプラグインとして実装できることは、すべてツールでできる

**PMXエディタがプラグインへ向けて公開する `PEPlugin.dll` の公開APIで成し遂げられる機能を、
危険な操作も含めて1つ残らずMCPのツールにする。** 何がそれに当たるかは
[能力台帳](../../catalog/observed/capability-ledger.json)が決める。

### PMXエディタのプラグインとして実装できて、メニュー項目の選択・ボタンの押下・ショートカットの入力1つで済むことは、ツールの1回の呼び出しでできる

**`PEPlugin.dll` の公開APIで成し遂げられる機能のうち、PMXエディタでメニュー項目の選択・ボタンの
押下・ショートカットの入力のいずれか1つで済むものは、MCPのツールの1回の呼び出しでできる。**
台帳が提供と分類した能力を複数組み合わせないと成し遂げられなくても、呼び出しは1回にまとめる。
**操作の対象が何件選ばれていても、行う操作が1つなら呼び出しも1回である。**

**取り消しの粒度も揃える。** その操作がPMXエディタで元に戻す1回で戻るなら、それに当たる呼び出し1回も
元に戻す1回で呼び出し前へ戻る。

**呼び出しが2回以上になってよいのは、応答が大きさの上限を超えて1回で返しきれないときだけとする。**

## 作業に依らない要件

作業のどれにも先立って満たすものをここへ置く。

### 危険操作の境界は、ツールの分離とクライアント側の許可で作る

`confirm` は**境界ではない**。エージェント自身が真を渡すので、渡すことを学べば素通りする。
エンドユーザーが止められるのは、**MCPクライアントがツールごとに求める許可**と、**エディタの
プラグインメニューからのホスト停止**の2つだけである。したがって:

- **上書き保存・モデル初期化・エディタ終了は、読み取り・編集のツールと別のツールにし、名前で
  区別できるようにする。** エンドユーザーがツールの名前だけを見て許可を決められることを条件とする。
- `confirm` は残す。ただしその意味は「**取り返しの付かない操作と知って呼ばれた**」という記録で
  あって、境界ではない。

### SDKの版が違っても待受を止めず、断るのは解決できないツールだけにする

ホストが参照するSDKは、実行時にエディタ同梱の版が読み込まれる。新しい版でメンバーが増えても
既存のツールは動くので、**版番号の不一致で全部を止めても、エンドユーザーには何も渡らない**。

- **解決できないメンバーを使うツールだけを個別に断り、ほかのツールは動き続ける。**
- **稼働しているSDKの版が分かるようにする。**

### エンドユーザーが1回だけ指示した操作を、2回実行しない

**結果が返らなかった呼び出しを、製品の側で自動的に送り直さない。** 実行されたかどうか分からない
要求をもう一度送ると、1回だけ指示された編集や保存が2回実行されうる。送り直すかどうかは
エンドユーザーが決める。

### 標準のMCPで動く製品にし、特定のクライアントに縛られない

stdioの標準のMCPで動くことを要件とし、**Claude Code は検証に使う参照クライアントに留める**。

- **Claude Code でしか成り立たない機能を作らない。**
- 特定のクライアント向けの拡張は、**それを解さないクライアントが無視するだけで壊れない範囲**で
  あれば使ってよい。ただし応答の大きさを抑える手立ては、その拡張が無いクライアントでも働くように
  する。
- 1回の応答の大きさの上限は、**既定値を設定で変えられる形のまま置く**。

### 受け取った側は、渡した物だけで導入・更新・アンインストールを完了できる

導入に使うのはホストのDLLとブリッジの実行ファイルとインストール指示書の3つとする。パッケージには
このほかに、配布する物について法と利用規約が求める表示の転記物が入る。

- **その3つだけで、導入も更新もアンインストールも完了できる。** 受け取った側はリポジトリを持たない
  ので、そこを見ないと補えない手順を残さない。
- **.NETランタイムの追加の導入を要しない。** 対応するOSだけを満たす環境には共有ランタイムが無い。
- **再配布を禁じられている物を配布物へ入れない。** PMXエディタ配布物の利用規約が、パッケージ内
  データの再配布を禁じる。
- **配布物に入る第三者のコードについて、ライセンスと通知の表示を欠かさない。** 表示の対象は
  **実際に出荷する物**とする——参照しただけで出荷しない物を数えても、出荷する物を数え落として
  いれば表示は欠ける。
